 **Biometric Attendance System**

This project demonstrates a simulated biometric attendance system using fingerprint with data logging through manual entry in python and by push button in circuit.

**Technologies Used:**
1.Python
2.SimulIDE
3.Arduino IDE

**Working**
1. Simulated fingerprint IDs are checked using Python.
2. Valid student IDs are marked present.
3. Invalid IDs are rejected.
4. Attendance records are stored in a CSV file.
5. The Arduino circuit uses push buttons to simulate valid and invalid fingerprint inputs.
6. Green LED indicates accepted input, while red LED indicates rejected input.

## Project Files
- `attendance.py` – Python attendance program
- `attendance.csv` – Attendance records
- `biometric fingerprint.sim1` – circuit design
- `biometric.ino` – Arduino program
- SimulIDE circuit file – Simulated hardware design

It was completely simulation work
